## 🚀 1-Click Deployment on Vercel

This repository is optimized for instant zero-configuration deployment on **[Vercel](https://vercel.com)**:

1. Log into your **Vercel** account.
2. Click **Add New...** &rarr; **Project**.
3. Import this repository: `rashpalsinghpunjab/hr-website`.
4. Leave all build settings as default (Framework Preset: **Other**, Build Command: empty).
5. Click **Deploy**.
6. **Connect your custom domain (`hrglobalimportexport.com`):**
   - Go to **Project Settings** &rarr; **Domains**.
   - Add `hrglobalimportexport.com` and `www.hrglobalimportexport.com`.
   - Update your DNS records as prompted by Vercel.
